# Исследование уязвимости динамической памяти Row hammer
Исследовать механизмы возникновения и эксплуатации уязвимости динамической памяти Row hammer, разработать рекомендации по защите от данного класса атак.
1. Изучить теоретические основы архитектуры динамической памяти (DRAM) и физические предпосылки возникновения уязвимости Row hammer.
2. Проанализировать существующие методы и сценарии эксплуатации уязвимости и их влияние на целостность данных.
3. Исследовать особенности взаимодействия подсистемы управления памятью ОС Linux с аппаратным обеспечением для оценки возможности эксплуатации уязвимости в программной среде.
4. Провести эксперимент для демонстрации возможности возникновения битовых инверсий при эксплуатации Row hammer.
5. Проанализировать существующие аппаратные и программные методы защиты и сформулировать рекомендации по минимизации рисков эксплуатации уязвимости.
